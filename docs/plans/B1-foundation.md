# B1 — Backend Foundation Implementation Plan

> **Summary:** Track B's first plan: repo tooling, FastAPI skeleton, error format, real-Postgres test setup, all 29 tables with constraints and migrations, login and roles, uploads, live-event stream, real master-data CRUD, and the full API contract as example-data endpoints so Track A can build every screen.
> **Last updated:** 2026-10-10

**How to use this plan:** work through the tasks in order. Each task is a test-first cycle; tick the checkbox steps as you go and commit at the end of each task. Do not skip the "run it and watch it fail" steps.

**Goal:** A running API on the laptop with the complete database schema, working login, real master-data endpoints, and every other endpoint in spec §12 returning realistic example data in its final shape — plus `contracts/types.ts` generated from it.

**Architecture:** One FastAPI app under `services/api`, SQLAlchemy 2 models with all constraints, Alembic migrations, Pydantic request/response models per module. Module endpoints other than master data are *stubs*: they validate input and enforce roles for real, then return example data; later plans (B2–B7) replace the stub bodies without changing the shapes. Derived-status views are **not** in B1 — each view is added by the plan that owns its logic (B2–B5), where it can be tested properly.

**Tech Stack:** Python 3.12, uv, FastAPI, Uvicorn, SQLAlchemy 2, Alembic, psycopg 3, Pydantic v2 + pydantic-settings, PyJWT, bcrypt, python-multipart, pytest + httpx; PostgreSQL 16; npm root scripts with `concurrently` and `openapi-typescript`.

**Spec:** `docs/specs/2026-10-10-textile-mill-design.md` (read §3, §4, §6, §12, §13 before starting).

## Global Constraints

- Runs natively (no Docker) on macOS and Windows: Postgres 16 local, `uv` for Python, npm for scripts. From the repo root: `npm run dev:api`, `npm run test:api`, `npm run contracts`.
- Every error response has the shape `{"code", "message", "field", "fields"}` (`fields` only for validation errors).
- Required text is trimmed and must be non-empty; numbers in JSON are plain numbers (kg/metres/money); all money and quantity columns are `Numeric` in the database.
- Orders, lots, rolls, machines, dispatches and invoices are addressed by their human code in URLs (`ORD-0012`, `L-0017`, `R-0142`, `LOOM-04`, `DSP-0007`, `INV-0007`); master-data records by integer id.
- Buyer endpoints never accept a buyer id; it comes from the login.
- Only Track B writes migrations. `contracts/` is regenerated by Track B with `npm run contracts` and committed.
- Commit messages: plain imperative subject line, optional body, no trailers.
- Tests run against a real Postgres database `everest_test` — never mocks.

## Review Focus

1. **Same delivery entered twice** (same supplier, challan number and yarn type) → a clear `409 DUPLICATE_CHALLAN` on `challan_no`, never a 500. Test in Task 8.
2. **Whitespace-only required text** (e.g. supplier name `"   "`) → `422 VALIDATION_ERROR` naming that field. Test in Task 9.
3. **Expired, tampered or missing session cookie** → `401 NOT_AUTHENTICATED`, never a 500. Test in Task 5.
4. **Wrong role** (buyer calling a staff endpoint, staff calling the portal) → `403 FORBIDDEN`. Test in Task 5 and Task 13.
5. **Non-image or oversized upload, or a path-traversal file name** → `422 UNSUPPORTED_FILE` / `413 FILE_TOO_LARGE` / `404`, never a file written outside the uploads folder. Test in Task 6.

```python
from fastapi import FastAPI, Request
from fastapi.exceptions import RequestValidationError
from fastapi.responses import JSONResponse
from pydantic import BaseModel
from sqlalchemy.exc import IntegrityError
from sqlalchemy.orm import Session


class ErrorBody(BaseModel):
    code: str
    message: str
    field: str | None = None
    fields: dict[str, str] | None = None


class AppError(Exception):
    def __init__(self, code: str, message: str, *, field: str | None = None, status: int = 409):
        super().__init__(message)
        self.code = code
        self.message = message
        self.field = field
        self.status = status


# constraint name -> (code, field, message). Modules add their own entries.
KNOWN_CONSTRAINTS: dict[str, tuple[str, str | None, str]] = {}


def _friendly(msg: str) -> str:
    return msg.removeprefix("Value error, ")


def map_integrity_error(exc: IntegrityError) -> AppError:
    diag = getattr(exc.orig, "diag", None)
    name = getattr(diag, "constraint_name", None) or ""
    table = getattr(diag, "table_name", None) or ""
    sqlstate = getattr(exc.orig, "sqlstate", None)
    if name in KNOWN_CONSTRAINTS:
        code, field, message = KNOWN_CONSTRAINTS[name]
        return AppError(code, message, field=field)
    if sqlstate == "23505":
        field = name.removeprefix(f"uq_{table}_") or None
        return AppError("DUPLICATE", "This already exists", field=field)
    if sqlstate == "23503":
        return AppError("NOT_FOUND", "A referenced record does not exist", status=404)
    if sqlstate == "23502":
        return AppError("REQUIRED", "A required value is missing",
                        field=getattr(diag, "column_name", None), status=422)
    return AppError("INVALID_VALUE", f"Value not allowed ({name or 'constraint'})", status=422)


def commit(db: Session) -> None:
    try:
        db.commit()
    except IntegrityError as exc:
        db.rollback()
        raise map_integrity_error(exc) from exc


def install_error_handlers(app: FastAPI) -> None:
    @app.exception_handler(AppError)
    async def _app_error(_: Request, exc: AppError) -> JSONResponse:
        body = ErrorBody(code=exc.code, message=exc.message, field=exc.field)
        return JSONResponse(status_code=exc.status, content=body.model_dump())

    @app.exception_handler(RequestValidationError)
    async def _validation(_: Request, exc: RequestValidationError) -> JSONResponse:
        fields: dict[str, str] = {}
        for err in exc.errors():
            parts = [str(p) for p in err["loc"] if p not in ("body", "query", "path")]
            fields.setdefault(".".join(parts) or "request", _friendly(err["msg"]))
        first_field, first_msg = next(iter(fields.items()))
        body = ErrorBody(code="VALIDATION_ERROR", message=first_msg, field=first_field, fields=fields)
        return JSONResponse(status_code=422, content=body.model_dump())
```

```python
import datetime as dt

from sqlalchemy import CheckConstraint, DateTime, MetaData, Numeric, func
from sqlalchemy.orm import DeclarativeBase, Mapped, mapped_column

NAMING = {
    "ix": "ix_%(table_name)s_%(column_0_N_name)s",
    "uq": "uq_%(table_name)s_%(column_0_N_name)s",
    "ck": "ck_%(table_name)s_%(constraint_name)s",
    "fk": "fk_%(table_name)s_%(column_0_name)s_%(referred_table_name)s",
    "pk": "pk_%(table_name)s",
}

KG = Numeric(12, 3)
MONEY = Numeric(12, 2)


class Base(DeclarativeBase):
    metadata = MetaData(naming_convention=NAMING)


class IdMixin:
    id: Mapped[int] = mapped_column(primary_key=True)
    created_at: Mapped[dt.datetime] = mapped_column(DateTime(timezone=True), server_default=func.now())


def nonblank(column: str) -> CheckConstraint:
    return CheckConstraint(f"btrim({column}) <> ''", name=f"{column}_nonblank")
```

```python
import datetime as dt
from collections.abc import Callable

import bcrypt
import jwt
from fastapi import Depends, Request
from sqlalchemy.orm import Session

from app.config import settings
from app.core.errors import AppError
from app.db.models import User
from app.db.session import get_db

COOKIE_NAME = "everest_session"
ALL_ROLES = ("owner", "accountant", "store", "supervisor", "qc", "dispatch", "buyer")
STAFF = tuple(r for r in ALL_ROLES if r != "buyer")


def hash_password(password: str) -> str:
    return bcrypt.hashpw(password.encode(), bcrypt.gensalt()).decode()


def verify_password(password: str, hashed: str) -> bool:
    try:
        return bcrypt.checkpw(password.encode(), hashed.encode())
    except ValueError:
        return False


def create_token(user_id: int) -> str:
    exp = dt.datetime.now(dt.UTC) + dt.timedelta(hours=settings.jwt_ttl_hours)
    return jwt.encode({"sub": str(user_id), "exp": exp}, settings.jwt_secret, algorithm="HS256")


def read_token(token: str) -> int | None:
    try:
        payload = jwt.decode(token, settings.jwt_secret, algorithms=["HS256"])
        return int(payload["sub"])
    except (jwt.PyJWTError, KeyError, ValueError, TypeError):
        return None


def _not_authenticated() -> AppError:
    return AppError("NOT_AUTHENTICATED", "Please log in", status=401)


def session_user_id(request: Request) -> int:
    token = request.cookies.get(COOKIE_NAME)
    user_id = read_token(token) if token else None
    if user_id is None:
        raise _not_authenticated()
    return user_id


def current_user(request: Request, db: Session = Depends(get_db)) -> User:
    user = db.get(User, session_user_id(request))
    if user is None:
        raise _not_authenticated()
    return user


def require_roles(*roles: str) -> Callable[..., User]:
    def dependency(user: User = Depends(current_user)) -> User:
        if user.role not in roles:
            raise AppError("FORBIDDEN", "You don't have access to this", status=403)
        return user

    return dependency
```

```python
import asyncio
import json
import threading


def _offer(queue: asyncio.Queue, message: str) -> None:
    if not queue.full():
        queue.put_nowait(message)


class Broadcaster:
    """Fan-out of small change events to every open live stream.

    publish() may be called from any thread (sync route handlers run in a thread pool);
    each message is handed to the subscriber's own event loop with call_soon_threadsafe.
    """

    def __init__(self, max_queue: int = 100) -> None:
        self._max_queue = max_queue
        self._subs: dict[asyncio.Queue, asyncio.AbstractEventLoop] = {}
        self._lock = threading.Lock()

    def subscribe(self) -> asyncio.Queue:
        queue: asyncio.Queue = asyncio.Queue(maxsize=self._max_queue)
        with self._lock:
            self._subs[queue] = asyncio.get_running_loop()
        return queue

    def unsubscribe(self, queue: asyncio.Queue) -> None:
        with self._lock:
            self._subs.pop(queue, None)

    def publish(self, event_type: str, id: int | str | None = None) -> None:
        message = json.dumps({"type": event_type, "id": id})
        with self._lock:
            targets = list(self._subs.items())
        for queue, loop in targets:
            try:
                loop.call_soon_threadsafe(_offer, queue, message)
            except RuntimeError:
                self.unsubscribe(queue)


broadcaster = Broadcaster()
```

```python
async def events(request: Request, _: int = Depends(session_user_id)) -> StreamingResponse:
    queue = broadcaster.subscribe()

    async def stream() -> AsyncIterator[str]:
        try:
            yield "retry: 3000\n\n"
            while not await request.is_disconnected():
                try:
                    message = await asyncio.wait_for(queue.get(), timeout=15)
                    yield f"data: {message}\n\n"
                except TimeoutError:
                    yield ": ping\n\n"
        finally:
            broadcaster.unsubscribe(queue)

    return StreamingResponse(
        stream(), media_type="text/event-stream",
```

```python
from app.core.auth import current_user, session_user_id

router = APIRouter(prefix="/uploads", tags=["uploads"])

ALLOWED = {"image/jpeg": ".jpg", "image/png": ".png", "image/webp": ".webp"}
MAX_BYTES = 10 * 1024 * 1024
NAME_RE = re.compile(r"^[0-9a-f]{32}\.(jpg|png|webp)$")


class UploadOut(BaseModel):
    path: str
    url: str


def upload_root() -> Path:
    root = Path(settings.upload_dir).resolve()
    root.mkdir(parents=True, exist_ok=True)
    return root


@router.post("", response_model=UploadOut, dependencies=[Depends(current_user)])
async def upload(file: UploadFile) -> UploadOut:
    ext = ALLOWED.get(file.content_type or "")
    if ext is None:
        raise AppError("UNSUPPORTED_FILE", "Only JPEG, PNG or WebP photos", field="file", status=422)
    data = await file.read(MAX_BYTES + 1)
    if not data:
        raise AppError("EMPTY_FILE", "The file is empty", field="file", status=422)
    if len(data) > MAX_BYTES:
        raise AppError("FILE_TOO_LARGE", "Photos must be 10 MB or smaller", field="file", status=413)
    name = f"{uuid.uuid4().hex}{ext}"
    (upload_root() / name).write_bytes(data)
    return UploadOut(path=f"uploads/{name}", url=f"/api/uploads/{name}")


@router.get("/{name}", response_class=FileResponse, dependencies=[Depends(session_user_id)])
def download(name: str) -> FileResponse:
    if not NAME_RE.fullmatch(name):
        raise AppError("NOT_FOUND", "File not found", status=404)
    path = upload_root() / name
    if not path.is_file():
        raise AppError("NOT_FOUND", "File not found", status=404)
    return FileResponse(path)
```

```python
from collections.abc import Callable

from fastapi import APIRouter, Depends
from pydantic import BaseModel
from sqlalchemy import select
from sqlalchemy.orm import Session

from app.core.auth import STAFF, hash_password, require_roles
from app.core.errors import AppError, commit
from app.db.models import Buyer, FabricRecipeLine, FabricType, Machine, Shift, Supplier, User, Worker, YarnType
from app.db.session import get_db
from app.modules.master import schemas as s

router = APIRouter(tags=["master data"])
read_any_staff = require_roles(*STAFF)
owner_only = require_roles("owner")


def _get_or_404(db: Session, model, item_id: int):
    obj = db.get(model, item_id)
    if obj is None:
        raise AppError("NOT_FOUND", f"{model.__name__} not found", status=404)
    return obj


def register_crud(path: str, model, In: type[BaseModel], Patch: type[BaseModel], OutModel: type[BaseModel],
                  order_by, read_dep: Callable = read_any_staff) -> None:
    @router.get(path, response_model=list[OutModel], name=f"list{path}")
    def list_items(db: Session = Depends(get_db), _=Depends(read_dep)):
        return db.scalars(select(model).order_by(order_by)).all()

    @router.post(path, response_model=OutModel, status_code=201, name=f"create{path}")
    def create_item(body: In, db: Session = Depends(get_db), _=Depends(owner_only)):  # type: ignore[valid-type]
        obj = model(**body.model_dump())
        db.add(obj)
        commit(db)
        db.refresh(obj)
        return obj

    @router.patch(path + "/{item_id}", response_model=OutModel, name=f"update{path}")
    def update_item(item_id: int, body: Patch, db: Session = Depends(get_db), _=Depends(owner_only)):  # type: ignore[valid-type]
        obj = _get_or_404(db, model, item_id)
        for key, value in body.model_dump(exclude_unset=True).items():
            setattr(obj, key, value)
        commit(db)
        db.refresh(obj)
        return obj


register_crud("/suppliers", Supplier, s.SupplierIn, s.SupplierPatch, s.SupplierOut, Supplier.name)
register_crud("/buyers", Buyer, s.BuyerIn, s.BuyerPatch, s.BuyerOut, Buyer.name)
register_crud("/yarn-types", YarnType, s.YarnTypeIn, s.YarnTypePatch, s.YarnTypeOut, YarnType.code)
register_crud("/machines", Machine, s.MachineIn, s.MachinePatch, s.MachineOut, Machine.code)
register_crud("/workers", Worker, s.WorkerIn, s.WorkerPatch, s.WorkerOut, Worker.code)
register_crud("/shifts", Shift, s.ShiftIn, s.ShiftPatch, s.ShiftOut, Shift.start_time)


def _fabric_out(ft: FabricType) -> s.FabricTypeOut:
    return s.FabricTypeOut(
        id=ft.id, name=ft.name, width_in=float(ft.width_in), wastage_pct=float(ft.wastage_pct),
        recipe=[s.RecipeLineOut(yarn_type_id=line.yarn_type_id, yarn_type_code=line.yarn_type.code,
                                kg_per_metre=float(line.kg_per_metre)) for line in ft.recipe_lines],
    )


def _set_recipe(db: Session, ft: FabricType, recipe: list[s.RecipeLineIn]) -> None:
    for line in recipe:
        _get_or_404(db, YarnType, line.yarn_type_id)
    ft.recipe_lines.clear()
    db.flush()
    for line in recipe:
        ft.recipe_lines.append(FabricRecipeLine(yarn_type_id=line.yarn_type_id, kg_per_metre=line.kg_per_metre))


@router.get("/fabric-types", response_model=list[s.FabricTypeOut])
def list_fabric_types(db: Session = Depends(get_db), _=Depends(read_any_staff)):
    return [_fabric_out(ft) for ft in db.scalars(select(FabricType).order_by(FabricType.name))]


@router.post("/fabric-types", response_model=s.FabricTypeOut, status_code=201)
def create_fabric_type(body: s.FabricTypeIn, db: Session = Depends(get_db), _=Depends(owner_only)):
    ft = FabricType(name=body.name, width_in=body.width_in, wastage_pct=body.wastage_pct)
    db.add(ft)
    _set_recipe(db, ft, body.recipe)
    commit(db)
    db.refresh(ft)
    return _fabric_out(ft)


@router.patch("/fabric-types/{item_id}", response_model=s.FabricTypeOut)
def update_fabric_type(item_id: int, body: s.FabricTypePatch, db: Session = Depends(get_db), _=Depends(owner_only)):
    ft = _get_or_404(db, FabricType, item_id)
    data = body.model_dump(exclude_unset=True)
    recipe = data.pop("recipe", None)
    for key, value in data.items():
        setattr(ft, key, value)
    if recipe is not None:
        _set_recipe(db, ft, body.recipe)
    commit(db)
    db.refresh(ft)
    return _fabric_out(ft)


@router.get("/users", response_model=list[s.UserOut])
def list_users(db: Session = Depends(get_db), _=Depends(owner_only)):
    return db.scalars(select(User).order_by(User.username)).all()


@router.post("/users", response_model=s.UserOut, status_code=201)
def create_user(body: s.UserIn, db: Session = Depends(get_db), _=Depends(owner_only)):
    data = body.model_dump()
    user = User(password_hash=hash_password(data.pop("password")), **data)
    db.add(user)
    commit(db)
    db.refresh(user)
    return user


@router.patch("/users/{item_id}", response_model=s.UserOut)
def update_user(item_id: int, body: s.UserPatch, db: Session = Depends(get_db), _=Depends(owner_only)):
    user = _get_or_404(db, User, item_id)
    data = body.model_dump(exclude_unset=True)
    if "password" in data:
        user.password_hash = hash_password(data.pop("password"))
    for key, value in data.items():
        setattr(user, key, value)
    commit(db)
    db.refresh(user)
    return user
```
