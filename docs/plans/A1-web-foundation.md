# A1 — Web Foundation Implementation Plan

> **Summary:** Track A's first plan: Next.js app scaffold, typed API client generated from `contracts/`, standard error handling, the form pattern (no double submits, server errors under fields), role-based navigation, login and session gate, responsive app shell with design-system components and a page for every route in spec §11, live-update hook, and the HTTPS phone-camera check.
> **Last updated:** 2026-10-10

**How to use this plan:** work through the tasks in order (Task 7 has no dependencies and can be done at any point). Each task is a test-first cycle; tick the checkbox steps as you go and commit at the end of each task.

**Goal:** A logged-in user on a laptop or a phone sees the right menu for their role, every route in spec §11 exists, every request is typed from the contract, errors show properly, and the team knows whether live camera works on phones over our local HTTPS.

**Architecture:** Next.js App Router app in `apps/web`. The browser only ever calls `/api/*` on the web app's own origin; Next.js rewrites those to the FastAPI server, so the session cookie is same-origin. All response and request types come from `contracts/types.ts` (generated by Track B). Data fetching uses TanStack Query; forms use react-hook-form + zod; UI uses Tailwind + shadcn/ui.

**Tech Stack:** Next.js (latest, App Router, TypeScript), Tailwind CSS, shadcn/ui, lucide-react, TanStack Query, openapi-fetch, react-hook-form, zod, @hookform/resolvers, sonner; Vitest + Testing Library + jsdom for tests; Caddy for local HTTPS.

**Spec:** `docs/specs/2026-10-10-textile-mill-design.md` (read §3, §11, §12, §13 first). Backend contract: `contracts/types.ts` (from plan B1).

## Global Constraints

- Developer machine is **Windows**; every command below is for **PowerShell** run from the repo root unless it says otherwise.
- Never hand-write API request/response types — import them from `@contracts/types` (`paths`, `components`).
- Every API call goes through `call(api.GET(...))` / `call(api.POST(...))` from `@/lib/api`, so errors are always an `ApiError`.
- TanStack Query keys start with the area name: `["orders"]`, `["orders", code]`, `["floor"]`, `["stock"]`, `["me"]` — the live-update hook relies on this.
- Every submit button uses `useSubmitLock` + `<SubmitButton>`; no form can send twice.
- Phone-first: every screen must work at 360 px wide with no horizontal scrolling.
- Track A edits only `apps/web/`, `Caddyfile`, `docs/HRITWIK_TEAM_NOTES.md`, and (in later plans) `services/api/app/modules/people` and `services/api/app/modules/llm`. Never edit `contracts/` by hand.
- Commit messages: plain imperative subject line, optional body, no trailers.

## Review Focus

1. **Double tap on any submit button** (e.g. Log in) → exactly one request. Test in Task 3 and Task 4.
2. **Session expires mid-use** (any API call returns 401) → user is sent to `/login?next=<current page>` and returns there after logging in; `next` can never send them to another site. Test in Task 2 and Task 4.
3. **Server rejects a field** (e.g. `422` on `challan_no`) → the message shows under that field, not as a generic toast. Test in Task 3.
4. **API server is down or Wi-Fi drops** → a readable "Can't reach the server" state with a Retry button, never a blank page. Test in Task 2 and Task 5.
5. **Phone at 360 px** → no horizontal scroll, the menu opens from a button, the user's role menu is complete. Test in Task 5 (component test + manual check).

```ts
export type ErrorBody = {
  code: string;
  message: string;
  field: string | null;
  fields: Record<string, string> | null;
};

export class ApiError extends Error {
  constructor(public status: number, public body: ErrorBody) {
    super(body.message);
    this.name = "ApiError";
  }
  get code() {
    return this.body.code;
  }
  get field() {
    return this.body.field;
  }
  get fields() {
    return this.body.fields;
  }
}

let onUnauthorized: (() => void) | null = null;

export function setUnauthorizedHandler(fn: (() => void) | null) {
  onUnauthorized = fn;
}

function isErrorBody(value: unknown): value is ErrorBody {
  return typeof value === "object" && value !== null && "code" in value && "message" in value;
}

function toErrorBody(error: unknown, status: number): ErrorBody {
  if (isErrorBody(error)) return { field: null, fields: null, ...error };
  if (status >= 500) return { code: "SERVER_ERROR", message: "Something went wrong on the server.", field: null, fields: null };
  return { code: "REQUEST_FAILED", message: "The request failed.", field: null, fields: null };
}

export async function call<T>(request: Promise<{ data?: T; error?: unknown; response: Response }>): Promise<T> {
  let result: { data?: T; error?: unknown; response: Response };
  try {
    result = await request;
  } catch {
    throw new ApiError(0, {
      code: "NETWORK_ERROR",
      message: "Can't reach the server. Check the Wi-Fi and try again.",
      field: null,
      fields: null,
    });
  }
  const { data, error, response } = result;
  if (response.ok) return data as T;
  if (response.status === 401) onUnauthorized?.();
  throw new ApiError(response.status, toErrorBody(error, response.status));
}

export function errorMessage(err: unknown): string {
  return err instanceof ApiError ? err.body.message : "Something went wrong.";
}
```

```ts
import { useCallback, useRef, useState } from "react";
import type { FieldValues, Path, UseFormReturn } from "react-hook-form";
import { ApiError } from "./api/errors";

export function useSubmitLock() {
  const busy = useRef(false);
  const [pending, setPending] = useState(false);

  const run = useCallback(async <T,>(fn: () => Promise<T>): Promise<T | undefined> => {
    if (busy.current) return undefined;
    busy.current = true;
    setPending(true);
    try {
      return await fn();
    } finally {
      busy.current = false;
      setPending(false);
    }
  }, []);

  return { run, pending };
}

export function applyServerErrors<T extends FieldValues>(form: UseFormReturn<T>, err: unknown): string | null {
  if (!(err instanceof ApiError)) return "Something went wrong.";
  const fields = err.fields ?? (err.field ? { [err.field]: err.body.message } : {});
  const known = form.getValues() as Record<string, unknown>;
  let placed = false;
  for (const [name, message] of Object.entries(fields)) {
    if (name in known) {
      form.setError(name as Path<T>, { type: "server", message });
      placed = true;
    }
  }
  return placed ? null : err.body.message;
}
```

```tsx
"use client";
import { zodResolver } from "@hookform/resolvers/zod";
import { useState } from "react";
import { useForm } from "react-hook-form";
import { z } from "zod";
import { SubmitButton } from "@/components/common/submit-button";
import { Input } from "@/components/ui/input";
import { Label } from "@/components/ui/label";
import { api, call, type components } from "@/lib/api";
import { applyServerErrors, useSubmitLock } from "@/lib/forms";

type Me = components["schemas"]["Me"];

const schema = z.object({
  username: z.string().trim().min(1, "Enter your username").max(60),
  password: z.string().min(1, "Enter your password").max(72, "Password is too long"),
});
type Values = z.infer<typeof schema>;

export function LoginForm({ onSuccess }: { onSuccess: (me: Me) => void }) {
  const form = useForm<Values>({ resolver: zodResolver(schema), defaultValues: { username: "", password: "" } });
  const { run, pending } = useSubmitLock();
  const [formError, setFormError] = useState<string | null>(null);
  const { errors } = form.formState;

  const onSubmit = form.handleSubmit((values) =>
    run(async () => {
      setFormError(null);
      try {
        onSuccess(await call(api.POST("/api/auth/login", { body: values })));
      } catch (err) {
        setFormError(applyServerErrors(form, err));
      }
    }),
  );

  return (
    <form onSubmit={onSubmit} noValidate className="space-y-4">
      <div className="space-y-1.5">
        <Label htmlFor="username">Username</Label>
        <Input id="username" autoComplete="username" autoCapitalize="none" {...form.register("username")}
               aria-invalid={!!errors.username} />
        {errors.username && <p className="text-sm text-destructive">{errors.username.message}</p>}
      </div>
      <div className="space-y-1.5">
        <Label htmlFor="password">Password</Label>
        <Input id="password" type="password" autoComplete="current-password" {...form.register("password")}
               aria-invalid={!!errors.password} />
        {errors.password && <p className="text-sm text-destructive">{errors.password.message}</p>}
      </div>
      {formError && <p role="alert" className="text-sm text-destructive">{formError}</p>}
      <SubmitButton pending={pending} className="w-full">Log in</SubmitButton>
    </form>
  );
}
```

```tsx
                                  active && "bg-accent font-medium")}>
                <item.icon className="size-4" aria-hidden />
                {item.label}
              </Link>
            );
          })}
        </div>
```

```ts
"use client";
import { useQueryClient, type QueryClient } from "@tanstack/react-query";
import { useEffect } from "react";

export const EVENT_KEYS: Record<string, string[][]> = {
  "lot.changed": [["lots"], ["stock"]],
  "stock.changed": [["stock"], ["orders"], ["insights"]],
  "order.changed": [["orders"], ["portal"], ["insights"]],
  "machine.changed": [["floor"], ["machine"], ["insights"]],
  "run.changed": [["floor"], ["machine"], ["orders"], ["portal"]],
  "roll.changed": [["qc"], ["rolls"], ["orders"], ["dispatches"], ["portal"]],
  "qc.changed": [["qc"], ["rolls"], ["orders"], ["insights"]],
  "dispatch.changed": [["dispatches"], ["orders"], ["portal"], ["money"]],
  "payment.changed": [["money"], ["owner"]],
  "attendance.changed": [["people"], ["owner"]],
};

export const keysFor = (eventType: string) => EVENT_KEYS[eventType] ?? [];

export function handleLiveMessage(queryClient: QueryClient, rawData: string) {
  let type: unknown;
  try {
    type = (JSON.parse(rawData) as { type?: unknown }).type;
  } catch {
    return;
  }
  if (typeof type !== "string") return;
  for (const queryKey of keysFor(type)) void queryClient.invalidateQueries({ queryKey });
}

export function useLiveEvents() {
  const queryClient = useQueryClient();
  useEffect(() => {
    const source = new EventSource("/api/events");
    source.onmessage = (event) => handleLiveMessage(queryClient, event.data);
    return () => source.close();
  }, [queryClient]);
}
```

```tsx
"use client";
import { useRef, useState } from "react";
import { Button } from "@/components/ui/button";

export default function CameraCheck() {
  const video = useRef<HTMLVideoElement>(null);
  const [status, setStatus] = useState("not started");
  const secure = typeof window !== "undefined" && window.isSecureContext;

  async function start() {
    if (!window.isSecureContext || !navigator.mediaDevices?.getUserMedia) {
      setStatus("Live camera blocked: this page is not a secure context. Use the photo button below.");
      return;
    }
    try {
      const stream = await navigator.mediaDevices.getUserMedia({ video: { facingMode: "environment" } });
      if (video.current) {
        video.current.srcObject = stream;
        await video.current.play();
      }
      setStatus("Live camera works");
    } catch (err) {
      setStatus(`Camera error: ${(err as Error).name}`);
    }
  }

  return (
    <main className="space-y-4 p-4">
      <h1 className="text-xl font-semibold">Camera check</h1>
      <p>Secure context: <strong>{String(secure)}</strong></p>
      <Button onClick={start}>Start live camera</Button>
      <video ref={video} muted playsInline className="w-full max-w-md rounded border" />
      <label className="block space-y-1">
        <span className="text-sm">Fallback — take a photo:</span>
        <input type="file" accept="image/*" capture="environment"
               onChange={(e) => setStatus(`Photo chosen: ${e.target.files?.[0]?.name ?? "none"}`)} />
      </label>
      <p data-testid="status" className="font-medium">{status}</p>
    </main>
  );
}
```
